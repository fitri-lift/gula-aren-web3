Modul 1 Data Architecture

Klasifikasi Pemetaan Data (On-Chain vs Off-Chain)

Penerapan efisiensi biaya gas fee & perlindungan hak privasi data pribadi (PII).

Solana Devnet Architecture
Data Off-Chain (Database Local / Storage)
  • ❌ Nama & Kontak Penderes: Data pribadi (PII) wajib dilindungi privasinya.
  • ❌ File Foto Citra Fisik: Ukuran terlalu besar untuk disimpan langsung di blockchain.
  • ❌ Catatan Keuangan Internal: Bersifat privat untuk kelompok tani penderes.
Data On-Chain (Blockchain Solana Ledger)
  • ✅ Hash Sertifikat & Skor AI: Bukti integritas imun tidak bisa dimanipulasi.
  • ✅ Timestamp & Slot Block: Penanda waktu pasti pencetakan batch gula aren.
  • ✅ Public Key Validator: Identitas digital penjamin keaslian produk.
